# MatchaJob

An automated job aggregation and smart classification platform designed to collect, structure, and organize tech opportunities from multiple sources, including LinkedIn, Telegram groups, and job websites.

## Tech Stack

- **Backend:** Laravel 12
- **Frontend:** Blade + Tailwind CSS
- **Database:** PostgreSQL
- **Environment:** Docker & Docker Compose

## Quick Start
1. Start the PostgreSQL container:

```bash
docker compose up -d
